# 功能链路检查 · 2026-09-23

## 已修复

| 链路 | 原问题 | 处理 |
| --- | --- | --- |
| 收件箱 / AI 助理 → 资料 | 没有关联项目的资料缺少固定查看入口 | 项目空间集中显示“待归档资料”；选择项目后移入该项目资料 |
| 培训复盘 → 资料 | 沿用已取消的知识笔记去向 | 保存后进入项目资料，未关联项目时进入待归档资料；再次同步更新同一条记录 |
| AI 草稿 → 修改 → 保存 | 修改保存后草稿仍可确认，可能重复创建 | 记录保存与草稿完成在同一次持久化中提交，并记录可打开的目标 |
| 培训记录 → 关联项目 | 已生成的跟进任务、复盘资料没有完整同步 | 共用 TrainingModel.sync，同步项目归属，保留任务计划和已编辑的资料正文 |
| 培训清单 → 日程 | 修改开始时间可能遗留早于开始时间的结束时间 | 清除已无效的结束时间，保留仍有效的时间段 |
| 今日简报 → 任务安排 | 日历遗留的项目筛选可能隐藏今天的任务 | 从今日简报等其他模块进入任务分类时清除项目筛选 |
| 搜索 → 收藏详情 | 对话框打开了，但底层页面仍在原栏目 | 进入对应的提示词、Skill 或 Agent 收藏栏目后打开详情 |
| 页面导航 → 返回 | 替换浏览器历史导致返回跨过刚才的页面 | 主导航与日历视图切换保留历史；导航时清除搜索遮罩 |
| 已归档培训记录 | 从项目空间缺少集中入口 | 提供“查看全部培训记录（含已归档）”入口 |
| 已失效项目链接 | 页面返回列表但地址仍指向不存在的项目 | 显示提示并归一到项目空间地址 |
