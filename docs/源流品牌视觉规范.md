# 源流品牌视觉规范

## 品牌意向

**思有所流，行有所序。**

“源流”既是信息和灵感不断进入个人工作系统的过程，也是想法经过整理后成为行动、项目与知识的过程。品牌气质应当克制、清醒、有东方文化感，同时保持 AI 原生工作台的未来感。

## 标志含义

- 左侧三枚金色水滴取自汉字“氵”，代表进入工作台的灵感、信息与经验。
- 右侧三条水脉取自汉字“川”，不同节奏的曲线代表持续流动的工作与认知。
- “氵”与“川”共同构成一个现代中文水脉字印，不依赖英文字母建立识别。

标志保持开放，不使用封闭圆环，表达信息持续进入、理解持续生长。

## 标志文件

- `dist/assets/yuanliu-mark-dark.svg`：深色背景图形标。
- `dist/assets/yuanliu-mark-light.svg`：浅色背景图形标。
- `dist/assets/yuanliu-logo-dark.svg`：深色背景横版组合标。
- `dist/assets/yuanliu-logo-light.svg`：浅色背景横版组合标。
- `dist/assets/yuanliu-favicon.svg`：浏览器图标。

图形标最小显示尺寸为 24px；横版组合标建议宽度不低于 180px。标志四周至少保留一个中央菱形宽度的净空。

## 字体体系

### 品牌字标

使用现代细黑体：

`Hiragino Sans GB / STHeiti / PingFang SC / sans-serif`

- 字标使用 300 字重与较宽字距。
- 英文辅助标仅保留 `YUANLIU`，不在锁定标内重复品牌口号。

### 首页主标题

使用现代宋体风格：

`Songti SC / STSong / Source Han Serif SC / Noto Serif CJK SC / serif`

- 首页主标题使用 400 字重。
- 中文标题字距保持在 1–3px，避免过密或过度拉开。

宋体只承担首页主标题和品牌叙事，不用于按钮、表单、业务标题或长段正文。

### 界面与正文

使用现代无衬线字体：

`Inter / PingFang SC / Microsoft YaHei / sans-serif`

- 正文使用 400 字重。
- 业务页一级标题、导航、按钮和信息标题使用 500 字重。
- 当前状态或重要标签最多使用 600 字重。
- 数字采用等宽数字特性，便于日期、进度和统计值对齐。

## 品牌色

| 角色 | 深色模式 | 浅色模式 | 用途 |
|---|---|---|---|
| 夜幕底色 | `#0B0F19` | `#F5F6FA` | 页面背景 |
| 主文字 | `#E8E5EE` | `#292C3B` | 标志与一级信息 |
| 流动紫 | `#AFA6D7` | `#6F5B91` | 选中、关联与知识 |
| 秩序蓝 | `#93AAC9` | `#557493` | 进度、结构与辅助信息 |
| 节点金 | `#C6A970` | `#9A7340` | 标志节点与极少量品牌强调 |

香槟金只用于品牌节点和少量高价值提示，不能大面积用于按钮或背景。业务操作仍使用紫蓝体系，避免界面变成传统黑金风格。

## 使用原则

1. 品牌图形只出现一次作为页面主标识，不与其他大型装饰图形竞争。
2. 首页主标题可以使用宋体；业务标题、导航、按钮和正文统一使用无衬线字体。
3. 深浅模式只改变明度与对比，不改变标志结构。
4. 不给标志增加外发光、厚阴影、金属渐变或立体描边。
5. 不拉伸、旋转、拆分或重新排列图形中的四条流线与中央节点。
