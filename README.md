# 源流 · 个人工作台

一处起源，万绪成流。

**源码公开 · 个人及公司内部免费自用 · 禁止未经授权的对外商业化**

源流是一款为个人日常工作设计的工作台，用于收集信息、安排事项、推进项目和管理知识收藏，也支持使用自己的大模型 API Key 开启智能模式。

本仓库发布可独立运行的核心工作台。包含个人联系方式的介绍页、历史截图、备份和品牌探索稿不随代码发布。

## 功能

- **纵览**：工作入口与当前工作线索。
- **今日焦点**：处理今天安排的事项与需要留意的工作。
- **灵感拾萃**：随手收集想法、信息和链接，稍后整理。
- **行动时序**：任务管理、周日历和月日历。
- **项目纵横**：管理常规项目与培训项目，按模块组织任务和相关文档。
- **知识典藏**：收藏提示词、Skill 和 AI 产品网站。
- **工作记忆**：维护职责、表达偏好、长期规则、项目背景和关键决定。

## 下载与运行

安装 Python 3.9 或更新版本。运行工作台不需要安装 Node.js 或第三方 Python 包。

1. 在本仓库页面点击 **Code → Download ZIP**，下载后解压。
2. 打开终端，进入解压后的项目目录。
3. 运行：

```bash
python3 scripts/serve-local.py
```

Windows 上也可以使用：

```powershell
py -3 scripts/serve-local.py
```

4. 浏览器访问 **http://127.0.0.1:4567/**。

服务只监听本机地址。使用结束后，在运行服务的终端按 `Ctrl+C` 停止。

macOS 用户也可以双击 `启动源流.command` 启动后台服务；启动成功后手动访问上述地址。

直接打开 `dist/index.html` 可以使用标准模式；智能模式需要通过本机服务链接使用。两种打开方式属于不同的浏览器存储位置，切换前请导出备份，再在目标入口恢复。

## 智能模式

在工作台中选择智能模式，再选择服务商、质量档位并输入自己的 API Key。

- 支持 DeepSeek、硅基流动、智谱 AI、阿里云百炼、Kimi、OpenAI 及其他 Chat Completions 兼容服务。
- 经济、均衡、高质量三档会显示实际调用模型；高级设置支持修改 API 地址和模型 ID。
- 连接测试会真实调用服务商，可能产生 API 费用；网页会员或聊天产品订阅不一定包含 API 额度。
- Key 只保存在当前页面内存中，刷新或关闭后需要重新填写；后端按请求转发，不保存连接凭据。
- 用户发送需求时，会将允许使用的长期记忆与选定范围的当前工作发送给所选服务商。发送前可以展开查看上下文。
- 相关外部文档只提供名称，不自动读取正文。AI 生成的新事项需由用户确认后写入。

模型映射位于 `dist/model-registry.js`，具有复核日期；账户可用性、地域和模型参数以服务商实际支持为准。

## 数据与备份

工作记录保存在当前浏览器的本地存储中，不会因为上传本项目代码而自动同步到 GitHub。请通过工作台的“导出备份”定期备份，清理浏览器数据前先导出。

换电脑、换浏览器或更新运行目录时，请使用工作台的恢复备份功能迁移记录。仓库中的 `.gitignore` 会排除 `backups/`、`runtime/` 和本机配置；不要把个人导出文件或 API Key 放进其他待提交目录。

## 目录

```text
dist/       浏览器界面、品牌素材与业务逻辑
scripts/    本机 HTTP 服务与模型请求网关
tests/      业务逻辑与网关自动化测试
docs/       设计与功能说明
```

## 开发与验证

修改代码后重新启动本机服务，并刷新浏览器。前端自动化测试需要支持 `node --test` 的 Node.js。

```bash
node --test tests/*.test.cjs
python3 -m unittest tests/test_ai_gateway.py
```
